# maimuzo-claude-plugins-public

maimuzo の、公開している Claude Code のプラグインの置き場です。

## 入れ方

```
/plugin marketplace add maimuzo/maimuzo-claude-plugins-public
```

## プラグイン

| プラグイン | 中身 |
| --- | --- |
| [short-movie](plugins/short-movie/) | 製品の特徴を1つ伝える15〜30秒の紹介動画を、コンテ・キャラクター・絵コンテ・動画の順に、人間の確認を挟みながら作る |

```
/plugin install short-movie@maimuzo-public
```
